# [Завод Юпитер - оптика специального назначения]

##  Описание
Данный проект разработан в рамках прохождения **производственной практики** по направлению «Информационные системы и программирование». 

**Основная цель проекта:** [Разработка современной адаптивной веб-информационной системы с интуитивно понятной навигацией, обеспечивающей корректное отображение и удобное взаимодействие пользователей на устройствах с различными типами экранов]

Проект состоит из 4 основных страниц, реализующих следующий функционал:
1. **Главная страница** — [общая информация и навигация].
2. **[Вакансии]** — [список вакансий, их условия и контактная информация].
3. **[О нас]** — [информация о предприятии].
4. **[Производство]** — [список разделов и продуктов изготовляемых на предприятии и их описание].

##  Технологии и стек
Проект разработан с использованием следующих технологий:
*   **HTML5 / CSS** — верстка и стилизация
*   **JavaScript** — [синие частицы и навигация ]
